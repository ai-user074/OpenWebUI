# Open WebUI + Ollama - Ready for GitHub Codespaces

This folder is configured to automatically start Open WebUI with Ollama when opened in GitHub Codespaces or VS Code Dev Containers.

## Files

```
codespace/
├── devcontainer.json    # Codespaces/DevContainers config
├── docker-compose.yml   # Services: Ollama + Open WebUI
└── README.md           # Full documentation
```

## How It Works

1. Open this folder in **GitHub Codespaces** or **VS Code** → **Reopen in Container**
2. The Dev Container launches Docker Compose
3. Two services start automatically:
   - **Ollama** → pulls `tinyllama:1.1b` (small, fast, ~600MB)
   - **Open WebUI** → connects to Ollama, port 3000
4. When ready, the UI auto-opens at: **http://localhost:3000**

## First Run

- Pulls Docker images (~2GB)
- Downloads model (~100MB for tinyllama)
- Total: 3–5 minutes

Subsequent starts are instant (cached).

## Customize the Model

Edit `codespace/docker-compose.yml` → change the `ollama pull` line:

```yaml
ollama pull phi3:3.8b     # 2.2GB, better quality
ollama pull llama2:7b    # 4GB, good quality
ollama pull mistral:7b   # 4GB, strong performance
ollama pull tinyllama:1.1b  # 600MB, fast (current)
```

Restart the container to apply changes.

## Alternative: Use Root Config

This repo also has `.devcontainer/` at the root with the same setup for the entire project.
